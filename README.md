# パラレル生物図鑑：異世界観測ログ

日常のすぐ隣に迷い込んだ生物を探し、撮影して元の世界へ送り届けるブラウザゲーム。既存の33種類の生物とイラストを使い、図鑑完成と叔父さんからの最後の通信まで遊べます。

## 遊び方

1. 初回に名前を登録します。ホームには叔父さんからの「調査依頼」が表示され、手がかりから場所・観測時間・必要な持ち物を考えます。
2. 「調査に出発」から場所と観測時間を選び、ルートを選んで散策します。依頼の条件が合うと、対象生物の反応が強くなります。
3. 撮影は白い線と光が重なったときにタップ／スペース。8回成功で記録します。時間制限なしのモードもあります。
4. 調査依頼の対象を正しい条件で撮影すると依頼達成。叔父さんから短い追伸が届きます。行き詰まった場合は追加ヒントも見られます。
5. 図鑑で生態を読み、お気に入りや相棒を選びます。相棒とのふれあい・一緒の探索・撮影・アイテムで思い出が残ります。絆が増えるふれあいは1日3回までです。
6. 一部の生物は再観測すると「擬態中」「食事中」など別の生態を記録できます。生態観測は33種類の図鑑完成率とは別に保存されます。
7. 5種類で未確認エリアが解放。5・10・20・30・33種類で通信が届き、「記録」で読み返せます。全33種類で図鑑完成です。

現在の調査依頼は6件です。生態違いはまず3種類で試作しています。新機能は既存33種類の図鑑完成条件を変更しません。

生物・進捗・相棒・お気に入り・バッグ・調査依頼・生態観測・相棒との思い出は端末のlocalStorageに保存されます。同じ生物の再観測ではパラレルナッツ、1日1回のログインではキャンディが手に入ります。日次の区切りは端末の現地日付です。

APIキー、外部AIサービス、カメラ、位置情報、ログイン用アカウントは不要です。表示用フォントのみGoogle Fontsを使い、読み込めないときは端末のフォントになります。素材の読み込みには通信が必要です。現実の位置を追跡するゲームではありません。

## 保存と移行

右上の設定からJSONで書き出し・読み込みできます。復元には確認画面があり、現在の進捗を置き換えます。ブラウザや公開URLが変わると自動保存は共有されないため、先に書き出してください。ブラウザのデータ削除・プライベートブラウズ終了で保存が消える場合があります。

現行の保存形式は `services/progress.ts` のversion 2、キーは `parallel-zukan-save-v2` です。旧version 1（`parallel-zukan-save-v1`）は、発見済み生物・お気に入り・バッグ・相棒・絆・通信進捗などを維持したまま自動でversion 2へ移行します。旧キーのデータを移行時に削除・上書きはせず、新形式として別キーに保存します。

読み込み時は不正な生物・アイテム・依頼・生態・思い出IDを除外します。壊れた保存データは、可能であれば別のrecoveryキーへ退避してから初期状態を使います。保存領域自体が利用できない場合は元データを自動上書きしません。

## 開発と検証

Node.js 22.12以上。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

本番ビルドは型検査、ローカルでのTailwind CSS生成、サイズの大きな通信画像の圧縮を行います。元の画像は変更しません。

テストでは、全33種類への到達、出現条件、最終章、保存の検証・復元、version 1から2への移行、重複報酬、調査依頼の条件判定、生態違いの記録、相棒の絆・思い出、1日3回のふれあい制限、日次支給品の整合性を検証します。GitHub Actionsもテストと本番ビルドを実行します。

## Cloudflare Workers

既存のWorkers Buildsプロジェクト名は `isekai`。`wrangler.jsonc` で `dist` を静的配信します。

- ビルドコマンド：`npm run build`
- デプロイコマンド：`npx wrangler deploy`
- Node.js：22以上
- アプリ用の環境変数・APIキー・データベース：不要

Workers Buildsの既存Git連携がmainの更新を公開します。Cloudflareの成功チェックと実際の公開画面の両方を確認してください。手動配信する場合も先に `npm run build` を実行します。

## コンテンツ追加

生物本体は `constants.ts` の `CREATURES` と `public/zukan` に完全なデータと画像を追加します。実装のない仮データは収集対象に含めません。種類を増やした場合は物語の本文・節目とテストも更新します。

調査依頼は `data/missions.ts`、試作中の生態違いは `data/behaviors.ts`、相棒の反応・思い出表示は `services/buddy.ts` で管理します。現行の生物には進化先データがないため、絆100%は「最高の相棒」として扱います。

既存の宣伝映像素材・Remotionソースは残しています。ゲームの実行時には読み込みません。
