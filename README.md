# パラレル生物図鑑：異世界観測ログ

いつもの景色に、小さな違和感。叔父さんの手がかりを頼りに、33種類の異世界生物を調べるブラウザゲームです。

## 今回の探索

あみだくじは廃止しました。場所と時間を選ぶと、既存の風景の中に最大3つの痕跡が現れます。音・足あと・光などの特徴を読み、調べる対象を自分で選びます。選ぶたびに中身が抽選し直される仕組みではなく、1回の調査中は同じ痕跡と結果を保持します。すべての対象種に固有の痕跡を用意しました。

依頼の場所・時間・持ち物が合えば、対象生物の痕跡が必ず候補に含まれます。持ち物が必要な依頼では、足りない道具を「金属の落とし物」から回収できます。回収後、新しい調査を始めると持ち物の条件が反映されます。調査に時間制限はなく、別の痕跡もあとから調べられます。同じ調査内の落とし物を重複回収はできません。

生物に近づいたらパラレル・カムで撮影します。光と白線が重なる瞬間にタップ／スペースを8回成功させます。「ゆっくり撮影」は時間無制限で、光が線の上で待ちます。撮影に成功すると名前と生態が図鑑に登録されます。

## 図鑑・相棒・記録

未発見のカード、詳細、本の図鑑では正体を伏せ、番号・スケッチ・生息地・時間を手がかりとして表示します。名前検索は発見済みのみ、未発見は番号や生息地で探せます。図鑑には発見済み／未発見／お気に入りの絞り込みがあります。

6件の調査依頼を自分のペースで進められ、達成後の追伸は「記録」で読み返せます。相棒の最近の思い出はホームに1件を表示し、全件を展開できます。絆が増える通常のふれあいは1日合計3回（相棒を変えても同じ枠）。固有反応は回数にかかわらず楽しめます。

再観測の生態違いは深紅果実蟲・葉菜齧歯・光トンボの3種、合計6記録です。生態の記録は図鑑の詳細と「記録」で読み返せます。これは33種類の図鑑完成率とは別管理です。5種類で未確認エリアが開き、5・10・20・30・33種類で物語の通信が届きます。

## 保存

保存は端末のlocalStorageです。現在の形式はversion 2、キーは `parallel-zukan-save-v2`。旧version 1 (`parallel-zukan-save-v1`) は既存の発見・相棒・絆・バッグ等を保って移行し、古いキーを削除しません。

設定からJSONを書き出し・読み込みできます。端末・ブラウザ・公開URLの変更前にバックアップしてください。異なるURLでは自動保存が共有されません。壊れた保存データは可能な場合に退避し、退避できない場合は自動上書きを止めます。

APIキー、外部AI、実際のカメラ・位置情報・アカウント登録は不要です。Google Fontsが使えない場合は端末のフォントにフォールバックします。

## 開発・検証

Node.js 22.12以上（`.node-version` は22）。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

GitHub Actionsは型検査・ロジックテスト・本番ビルドに加え、実Chromeでの画面操作を行います。320×700 / 390×844 / 1440×900で出発ボタンが初期画面内にあり押せること、タップ領域、可視画像、はみ出しを検証します。6依頼はカメラのキーボード操作まで含めて達成し、道具入手・重複回収防止・生態再観測・保存復元・絆上限も確認します。

`Browser journeys and screenshots` のArtifactsにPNG、確認用JPEG、`audit.json`が残ります。スクリーンショットを人が見て確認するための証拠であり、画像差分の全自動判定ではありません。失敗時にも取得できた画像とDOM情報を保存します。

ローカルで同じブラウザ検証を行う場合はChromeまたはChromiumを用意し、4173でpreviewを起動して実行します。

```sh
python -m pip install 'playwright==1.55.0' 'Pillow==11.3.0'
TZ=Asia/Tokyo python scripts/ui-check.py
```

## Cloudflare

`wrangler.jsonc` は既存の `isekai` Workerで `dist` をSPA配信します。ビルド `npm run build`、配信 `npx wrangler deploy`。Git連携はmainを対象にします。ビルド時に素材のサイズ・個数を事前確認し、CIで `wrangler deploy --dry-run` も行います。これらの成功は公開成功そのものではありません。CloudflareのWorkers Builds結果と公開URLの両方を確認してください。

`build-info.json` で配信されているコミットを識別でき、設定画面にも短縮版を表示します。OGP画像は既存素材からビルド時に生成します。元画像は変更しません。

過去にWorkers Buildsの失敗を確認しています。GitHubからは詳細なCloudflareログ・アカウント設定を取得できていないため、原因や復旧を確認せず成功と断定しないでください。

## 内容を追加する場所

- 生物本体：`constants.ts` と `public/zukan/`
- 痕跡の文章：`data/fieldSignals.ts`
- 調査の組み立て：`services/field.ts`
- 依頼：`data/missions.ts`
- 生態記録：`data/behaviors.ts`
- 相棒の反応：`services/buddy.ts`

既存の映像素材・Remotionソースは保管していますが、ゲーム実行時には読み込みません。研究室・発見カード・ニックネーム・生物固有の長いエピソードは今後の候補です。
