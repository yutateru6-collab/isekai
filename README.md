# パラレル生物図鑑：異世界観測ログ

日常のすぐ隣に迷い込んだ生物を探し、撮影して元の世界へ送り届けるブラウザゲーム。既存の33種類の生物とイラストを使い、図鑑完成と叔父さんからの最後の通信まで遊べます。

## 遊び方

1. 初回に名前を登録し、「調査に出発」から場所と観測時間を選びます。
2. ルートを選んで散策。場所・時間に合った生物かアイテムが見つかります。
3. 撮影は白い線と光が重なったときにタップ／スペース。8回成功で記録します。時間制限なしのモードもあります。
4. 図鑑で生態を読み、お気に入りや相棒を選びます。ふれあいとアイテムで絆が上がり、相棒を変えても各生物の絆は残ります。
5. 5種類で未確認エリアが解放。5・10・20・30・33種類で通信が届き、「記録」で読み返せます。全33種類で図鑑完成です。

生物・進捗・相棒・お気に入り・バッグは端末のlocalStorageに保存されます。同じ生物の再観測ではパラレルナッツ、1日1回のログインではキャンディが手に入ります。日次の区切りは端末の現地日付です。

APIキー、外部AIサービス、カメラ、位置情報、ログイン用アカウントは不要です。表示用フォントのみGoogle Fontsを使い、読み込めないときは端末のフォントになります。素材の読み込みには通信が必要です。現実の位置を追跡するゲームではありません。

## 保存と移行

右上の設定からJSONで書き出し・読み込みできます。復元には確認画面があり、現在の進捗を置き換えます。ブラウザや公開URLが変わると自動保存は共有されないため、先に書き出してください。ブラウザのデータ削除・プライベートブラウズ終了で保存が消える場合があります。

保存形式は `services/progress.ts` のversion 1、キーは `parallel-zukan-save-v1`。不正なIDは除外し、壊れた保存データは読み込み時に別キーへ退避します。旧バージョンは発見・相棒を永続保存していなかったため、それらを復元する旧データはありません。

## 開発と検証

Node.js 22.12以上。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

本番ビルドは型検査、ローカルでのTailwind CSS生成、サイズの大きな通信画像の圧縮を行います。元の画像は変更しません。テストでは全33種類への到達、出現条件、最終章、保存の検証・復元、重複報酬、絆、日次支給品の整合性を検証します。GitHub Actionsもテストとビルドを実行します。

## Cloudflare Workers

既存のWorkers Buildsプロジェクト名は `isekai`。`wrangler.jsonc` で `dist` を静的配信します。

- ビルドコマンド：`npm run build`
- デプロイコマンド：`npx wrangler deploy`
- Node.js：22以上
- アプリ用の環境変数・APIキー・データベース：不要

Workers Buildsの既存Git連携がmainの更新を公開します。Cloudflareの成功チェックと実際の公開画面の両方を確認してください。手動配信する場合も先に `npm run build` を実行します。

## コンテンツ追加

`constants.ts` の `CREATURES` と `public/zukan` に完全な生物データと画像を追加します。実装のない仮データは収集対象に含めません。種類を増やした場合は物語の本文・節目とテストも更新します。現行の生物には進化先データがないため、絆100%は「最高の相棒」として扱います。

既存の宣伝映像素材・Remotionソースは残しています。ゲームの実行時には読み込みません。
